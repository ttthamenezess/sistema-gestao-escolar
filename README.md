# 🏫 Sistema de Gestão Escolar

Sistema web desenvolvido para auxiliar no controle de **alunos**, **mensalidades** e **recibos** de uma escola.

O projeto foi criado com foco em resolver uma necessidade real de organização administrativa e financeira, centralizando informações importantes em uma aplicação simples, acessível e funcional.

---

## 📌 Visão Geral

O **Sistema de Gestão Escolar** permite cadastrar alunos, controlar mensalidades por mês e ano, autenticar usuários e gerar recibos em formato `.txt`.

A proposta é facilitar a rotina administrativa de uma escola, oferecendo uma solução prática para controle financeiro e organização dos dados.

## 🗄️ Banco de Dados

O projeto utiliza o **Supabase** como solução de banco de dados e autenticação.

O Supabase foi utilizado para:

- Armazenar dados dos alunos
- Controlar informações financeiras
- Gerenciar autenticação de usuários
- Permitir persistência dos dados da aplicação
